# Ảnh minh hoạ

Thư mục này giữ ảnh cho README. Ba tệp sau **đang thiếu** và phải được bổ sung
trước khi phát hành — README hiện đang tham chiếu tới chúng và sẽ hiện ảnh vỡ:

| Tệp | Nội dung cần chụp |
|---|---|
| `demo.gif` | Bôi đen một từ, nút hiện ra, bấm vào, popup mở với kết quả. Khoảng 5–8 giây. |
| `popup-word.png` | Popup của một từ đơn: phiên âm, nghĩa chính, loại từ, các nghĩa khác. |
| `popup-sentence.png` | Popup của một câu: chỉ có bản dịch, không có khu vực từ điển. |
| `deepl-key.png` | Trang Account → API keys của DeepL, **đã che khoá thật**. |
| `google-cloud-key.png` | Trang Credentials của Google Cloud, **đã che khoá thật**. |

⚠️ Che kỹ khoá API trong mọi ảnh chụp. Làm mờ thôi là không đủ — hãy che hẳn
bằng một khối đặc.
